### From The Coding Train

First off, I adore Daniel Shiffman. He's a huge inspiration to how I want to approach coding and, to be honest, life in general. So as a part of learning Rust, I decided to run through his Coding Challenges (as well as his Nature of Code series) and work to port them over to Rust using Nannou. These won't be perfect, I won't "go the extra mile" each time, but I will sometimes add my own flair or experiment with the challenge. This will be my repo for these challenges as I am learning. I may revisit them as I become more confident both as a programmer in general and as a Rustacean.
